# One Line, Zero Use: The Useless Superpower Sprint

A make.fun entry: a tiny deterministic Python program that writes one line — a useless superpower — to `/output/entry.txt`.

> I can read my plants' minds, but only while I'm asleep, so I wake up every morning knowing the fern thinks I'm a disappointment.

Run it with:

```sh
python3 main.py
```
